# Nordhealth Interview Task

## Project Overview
This project is part of an interview task for Nordhealth, aimed at developing automated tests using Playwright and JavaScript.

## Technologies Used
- **Playwright**: Used for end-to-end browser automation testing.
- **JavaScript**: Primary language for writing test scripts.
- **Node.js**: JavaScript runtime environment.
- **VS Code**: IDE used for development.

## Installation Instructions
To get started with this project, follow the steps below:

1. Clone the repository:
    ```bash
    git clone https://github.com/asserttrue1/nordhealth-interview-task.git
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Run tests:
    ```bash
    npx playwright test
    ```
